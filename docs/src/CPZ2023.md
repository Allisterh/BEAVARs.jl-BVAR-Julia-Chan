# CPZ2023

This page documents the mixed-frequency CPZ-style workflow in the current package version without relying on stale internal helper names that are not part of the public API.

The package currently exposes the mixed-frequency model variants through the regular model interfaces, notably `makeSetup`, `makeDataSetup`, and `beavar`. In the present repository, the concrete mixed-frequency implementations are provided through the model types `BEAVARs.CPZ2023dev_type`, `BEAVARs.Blagov2025_type`, and `BEAVARs.Blagov2027_type`.

Use the setup and data-preparation helpers for the active model type and then call the main estimation routine via the public interface. The package documentation for the relevant model-specific pages is the correct reference for the detailed implementation.
